# 阶段三运行与验证结果

验证日期：2026-10-19。阶段三已完成实际训练的因果 TCN、Physics-EKF、Hybrid-EKF、同数据四方法比较、三条完整独立测试飞行及结果保存。阶段四的持久未知外力状态尚未实现。

## 实现与实验边界

沿用世界 ENU、机体 FLU、Hamilton `wxyz` 和右局部姿态误差。四方法共用原始 UWB、传感器噪声标定与阶段二独立先验；首帧 LS 仅用于初始化，不重复更新。LS 报告天线位置，不借真实姿态换算机体位置。在线估计接口只接收 IMU/UWB/RPM，真值在估计保存之后用于评价。

Physics-EKF 与 Hybrid-EKF 用 RPM 产生的力预测位置和速度、陀螺传播姿态，加速度计仅作比力观测。公开误差顺序仍为 `[δp,δv,δθ,δba,δbg]`。内部六维辅助量保存当前陀螺噪声与机体模型力误差；同一力误差同时进入预测和比力观测，保留状态/辅助量交叉协方差，并采用联合 Joseph 更新和右雅可比重置。

两种动力学方法固定使用每轴 0.25 N 的模型力误差先验，再加入 RPM 白噪声经力雅可比映射的协方差，不按结果调权。名义质量为 1.5 kg、`kf=1e-5 N/(rad/s)²`，名义线性/二次阻力均为零；参数独立存放于 `config/hybrid.yaml`。真实仿真保留阶段一非零阻力。模型接口及数学细节见 [方法说明](methods-dynamics.md)。

短期力辅助量在新 RPM 到达时替换，不是阶段四的持久未知外力状态。TCN 全部历史输入噪声与当前状态的相关性尚未完整增广，采用给定历史下固定条件误差的近似；不能由此宣称精确统计一致性。

## 实际训练与独立测试

运行环境为 Python 3.12.7、NumPy 1.26.4、PyTorch 2.7.1+cpu，训练与推理均使用 CPU 单线程。网络为三层、32 通道、卷积核 3 的因果 TCN；输入形状为 `10×7`，每帧是测量陀螺三轴与四电机 RPM。10 个 100 Hz 样本的首尾跨度为 90 ms，未满窗口前在线残余为零。

共生成 18 条 18 秒飞行，覆盖圆、八字、变速、加减速和悬停，并改变幅度、周期和方向。所有训练飞行关闭独立未知外力，标签为真实机体系气动力减去名义气动力；标签不含世界系外力、质量或推力误差。真值只用于离线标签与评价。按整条飞行划分，不随机打散重叠窗口：

| 划分 | 飞行数 | 种子 | 窗口数 |
| --- | ---: | --- | ---: |
| 训练 | 12 | 100–111 | 21504 |
| 验证 | 3 | 200–202 | 5376 |
| 测试 | 3 | 300–302 | 5376 |

输入/输出归一化只用训练集。训练 60 个 epoch，按验证误差选中第 43 个 epoch；没有根据测试定位结果重新选择权重。训练耗时 32.28 s，验证集残余力三维 RMSE 为 0.029664 N。保存的训练曲线以原始三维力误差平方均值 N² 表示，归一化优化目标单独记录。

| 独立测试指标 | 零残余物理基线 | 已训练 TCN/混合模型 |
| --- | ---: | ---: |
| 气动残余力三维 RMSE（N） | 0.118694 | 0.042247 |
| 世界加速度三维 RMSE（m/s²） | 0.079609 | 0.029472 |

TCN 残余力各轴 RMSE 为 `[0.034061, 0.024948, 0.001521] N`。分飞行气动残余力结果如下，全部测试飞行均保留：

| 测试飞行 | 物理零残余 RMSE（N） | TCN RMSE（N） |
| --- | ---: | ---: |
| `test_300_circle` | 0.134124 | 0.025196 |
| `test_301_figure_eight` | 0.108336 | 0.048062 |
| `test_302_variable_speed` | 0.111979 | 0.049089 |

单窗口 CPU 推理 200 次，平均 0.4564 ms、95 分位 0.5632 ms。该计时是本机单窗口测试，不等于完整滤波实时性能保证。短陀螺/RPM 历史通常不能唯一确定平移速度和气动力，网络只是所给飞行分布内的经验条件预测。

## 默认场景四方法定位

输入为 `results/phase1`，12 秒、种子 42、八字、无独立未知外力。主比较使用相同 121 个 UWB 时刻的天线位置，三维 RMSE 定义为 `sqrt(mean(||p_est-p_true||²))`。RPE 是世界系 1 秒位移差的误差，不是完整 SE(3) 相对位姿误差。

| 方法 | 天线位置 RMSE（m） | 1 s 平移 RPE RMSE（m） |
| --- | ---: | ---: |
| UWB 单点 LS | 0.169001 | 0.235149 |
| UWB–IMU ESKF | 0.059598 | 0.067045 |
| Physics-EKF | 0.053482 | 0.053012 |
| Hybrid-EKF（已训练 TCN） | 0.052311 | 0.053169 |

混合模型的天线 RMSE 相比物理模型约降低 2.19%，但其平移 RPE 略高。三种滤波器在各自全部 2401 个输出事件时刻的状态指标采用等样本权重：

| 指标 | ESKF | Physics-EKF | Hybrid-EKF |
| --- | ---: | ---: | ---: |
| 机体位置 RMSE（m） | 0.062331 | 0.055872 | 0.054737 |
| 速度 RMSE（m/s） | 0.108827 | 0.105001 | 0.105023 |
| 姿态最短旋转角 RMSE（°） | 2.985953 | 2.963214 | 2.982711 |
| 加速度计偏置 RMSE（m/s²） | 0.030806 | 0.032789 | 0.017263 |
| 陀螺偏置 RMSE（rad/s） | 0.007453 | 0.007457 | 0.007532 |
| 原始测距 NIS/8 均值 | 0.981614 | 0.981860 | 0.981649 |
| 15 维 NEES 均值 | 14.402484 | 23.642237 | 19.761459 |

Hybrid 的速度和姿态误差也略高于 Physics。NIS 排除用于初始化的第一帧，120 次测距更新；NEES 为单次轨迹描述统计，时刻之间相关，不提供蒙特卡洛置信区间或一致性通过结论。

## 全部独立测试飞行的定位

使用上述 checkpoint 声明的全部三条测试飞行，每条 18 秒、181 个共同 UWB 时刻。四方法使用相同先验；即使真实初始偏航随飞行种子变化，也不把它写入滤波初值。没有因为某条轨迹不改善而剔除。

| 飞行 | LS RMSE（m） | ESKF RMSE（m） | Physics RMSE（m） | Hybrid RMSE（m） |
| --- | ---: | ---: | ---: | ---: |
| `test_300_circle` | 0.143420 | 0.040316 | 0.037392 | 0.036306 |
| `test_301_figure_eight` | 0.184241 | 0.054094 | 0.048165 | 0.047711 |
| `test_302_variable_speed` | 0.160069 | 0.050593 | 0.046034 | 0.046163 |

变速飞行中，Hybrid 的天线 RMSE 略差于 Physics。残余力测试误差降低并不保证闭环滤波全部状态和所有轨迹都改善；姿态、偏置、力误差及测距更新之间存在耦合。完整各状态、RPE、创新和诊断数值保存在 `results/stage3_validation/validation_report.json`，不只保留表中位置指标。当前样本数量和仿真条件不足以支持普遍优越性声明。

## 0.2 秒局部预测

这是单独的离线模型试验：每个起点只用真实位置、速度、姿态初始化，随后固定起点姿态、测量 RPM、已产生的最近 TCN 残余及由此得到的加速度，按匀加速度公式预测终点。期间不以真值重置状态。这不是完整非线性滚动仿真，也不属于在线定位精度。

1201 个 RPM 候选起点中，1181 个具有精确匹配的真实终点，末尾 20 个超出数据区间而排除。两模型使用相同起点、终点和 0.2 s 时长；没有未来输入、残余插值或真值插值。

| --- | ---: | ---: |
| 起点加速度（m/s²） | 0.093803 | 0.053149 |
| 0.2 s 速度增量（m/s） | 0.080059 | 0.069948 |

- checkpoint 防误用测试先观察 4 项失败、2 项通过，增加名义气动定义和飞行种子校验后 6 项全通过；截断训练飞行也不能用于正式独立对比。
- 独立审查复算一维共享力 Gaussian 的连续条件化与传播，均值/协方差最大差分别为 `2.22e-16`、`1.11e-16`；随机姿态/非等向阻力下传播、辅助误差和比力雅可比有限差分最大差均小于 `1e-9`。
- 独立审查重算 18 条飞行输入指纹、训练集归一化、checkpoint 测试预测、定位指标和局部预测指标，未发现重要未解决问题。

## 运行命令与文件

在项目根目录执行，已有数据与 checkpoint 时可以跳过仿真和训练：

```powershell
python -m pip install -r requirements-learning.txt
$env:MKL_THREADING_LAYER='SEQUENTIAL'
python main.py
python -m experiments.train_residual --config config/hybrid.yaml --output results/residual_training
python -m experiments.plot_training --training results/residual_training
python -m experiments.run_stage3 --dataset results/phase1 --output results/phase3
python -m experiments.validate_stage3
python -m pytest -q --basetemp=results/pytest_tmp
```

本机 Conda MKL 与 Torch 的 OpenMP DLL 冲突通过导入数值库前设置 `MKL_THREADING_LAYER=SEQUENTIAL` 处理。CLI 与测试收集已设置缺省值；不要用忽略重复 OpenMP 库的环境开关掩盖冲突。

| 目录 | 主要产物 |
| --- | --- |
| `results/residual_training/` | `residual_tcn.pt`、`training_report.json`、`training_history.json`、`test_predictions.npz`、`source_manifest.json`、完整飞行数据与训练源码快照 |
| `results/phase3/baseline/` | 同数据 LS/ESKF 状态与诊断 |
| `results/phase3/` | `physics.npz`、`hybrid.npz`、`residual.npz`、四份观测诊断、`timing.npz`、设置、清单、`metrics.json`、复现核对与图 |
| `results/stage3_validation/` | 每条完整独立测试飞行的估计、图与汇总报告 |

`dynamics_manifest.json` 保存输入文件散列、模型散列、训练元数据与名义参数。科学数组采用无 pickle NPZ；数据目录默认被 Git 忽略，本次保留本地全部产物，未提交或推送。

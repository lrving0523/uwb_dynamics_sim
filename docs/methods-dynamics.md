# 阶段三物理与学习残余动力学方法

本阶段在相同 IMU、RPM 与原始 UWB 测距上运行 Physics-EKF 和 Hybrid-EKF，并保留阶段二的 UWB LS、ESKF 基线。两种动力学滤波器共享预测、观测、固定噪声和初始化算法；Hybrid-EKF 的机体系模型力额外包含真实训练 TCN 的气动残余预测。以下公式对应当前离散实现。

## 坐标、公开状态和模型力

世界系采用 ENU，机体系采用 FLU。Hamilton 四元数按 wxyz 保存，旋转矩阵 `R(q)` 将机体系向量转到世界系；右局部姿态误差满足 `q_true = q ⊗ Exp_q(δθ)`。公开名义状态为 `(p,v,q,ba,bg)`，误差顺序为：

```text
δx = [δp, δv, δθ, δba, δbg] ∈ R¹⁵
```

名义物理参数从 `config/hybrid.yaml` 独立配置，不从真实动力学参数或真实状态中读取。默认质量 `m=1.5 kg`、重力 `g=9.81 m/s²`、推力系数 `kf=10⁻⁵ N/(rad/s)²`，名义线性和二次阻力均为零。若配置阻力，名义相对气流、气动力与总机体系力为：

```text
v_relᴮ = R(q)ᵀ (v − w_nominal)
F_aero,nomᴮ = −d_linear ⊙ v_relᴮ − d_quadratic ⊙ |v_relᴮ| ⊙ v_relᴮ
ω_motor,i = RPM_m,i · 2π/60
F_physicsᴮ(q,v,RPM_m) = F_aero,nomᴮ + [0, 0, kf Σᵢ ω_motor,i²]ᵀ
F_hybridᴮ(q,v,RPM_m) = F_physicsᴮ(q,v,RPM_m) + F_residualᴮ
```

`⊙` 表示逐元素乘法，RPM 输入为测量转速。力单位为 N，世界加速度为 `R(q)Fᴮ/m + [0,0,−g]ᵀ`。混合模型在两个 RPM 事件之间保持当前网络预测；计算状态雅可比时将这项预测视为给定的条件输入，不重新运行网络。

## RPM 驱动平移、陀螺驱动姿态

动力学滤波器只使用已经到达的 RPM 和陀螺样本进行运动传播。设当前陀螺样本噪声的条件均值为 `μg`，当前模型力误差的条件均值为 `μF`，区间长度为 `Δt`，记 `Fᴮ` 为所选物理或混合模型力：

```text
ω = gyro_m − bg − μg
φ = ω Δt
q_half = q ⊗ Exp_q(φ/2)
R_half = R(q_half)
F_halfᴮ = Fᴮ(q_half, v, RPM_m) + μF
a_half = R_half F_halfᴮ/m + [0,0,−g]ᵀ

p_new = p + v Δt + a_half Δt²/2
v_new = v + a_half Δt
q_new = q ⊗ Exp_q(φ)
ba_new = ba
bg_new = bg
```

这里对姿态使用中点旋转，计算力时的速度仍是区间起点的估计速度。加速度计比力不参与上述 p/v 传播，只作为后面的观测使用一次。加速度计偏置因此不直接驱动平移预测；陀螺偏置通过姿态影响平移。

离散状态雅可比 `Φ` 和输入误差映射 `B` 直接对应这套积分。为明确中点耦合，令 `Jv=∂Fᴮ/∂v`、`Jθ=∂Fᴮ/∂δθ_half`、`R_delta_half=R(Exp_q(φ/2))`，以及 `Jr` 为 SO(3) 右雅可比，则：

```text
A_v = R_half Jv/m
A_θ,half = (−R_half [F_halfᴮ]× + R_half Jθ)/m
A_θ = A_θ,half R_delta_halfᵀ
A_bg = −A_θ,half Jr(φ/2) Δt/2

Φ_pv = I Δt + A_v Δt²/2       Φ_vv = I + A_v Δt
Φ_pθ = A_θ Δt²/2             Φ_vθ = A_θ Δt
Φ_pbg = A_bg Δt²/2           Φ_vbg = A_bg Δt
Φ_θθ = R(Exp_q(−φ))          Φ_θbg = −Jr(φ) Δt

B_[p,v,θ],g = Φ_[p,v,θ],bg
B_p,F = R_half Δt²/(2m)       B_v,F = R_half Δt/m
```

其余块保留相应的恒等或零结构。机体系残余力虽然在状态扰动时保持固定，转到世界系时仍通过 `−R_half[F_halfᴮ]×` 产生姿态导数。模型力、离散状态传播和比力观测的雅可比均有有限差分验证。

## 15 维状态与 6 维短期输入的联合 Gaussian

内部辅助量按以下顺序保存：

```text
u = [n_gyro, η_force] ∈ R⁶
μ = E[u | 已使用的观测] = [μg, μF]
ε = u − μ
Σ = Cov([δx, ε]) = [[P, C], [Cᵀ, S]]
P: 15×15，C: 15×6，S: 6×6
```

`n_gyro` 以减号修正测量角速度；`η_force` 以加号修正当前机体系模型力。当前力误差同时作用于运动预测和加速度计比力观测。因此，同一个 RPM 周期中，传播与比力更新使用同一随机量及其已经条件化的均值、协方差和状态交叉项。

该六维辅助量只代表当前输入周期的不确定性：陀螺部分在新陀螺样本到达时替换，力部分在新 RPM 到达时替换。公开状态和保存的运动状态协方差仍为 15 维。本阶段没有持久未知外力状态，也没有对未知外力执行随机游走估计。

在同一组输入辅助量保持期间，联合传播为：

```text
δx_new = Φ δx + B ε + ξ_bias
P_new = Φ P Φᵀ + Φ C Bᵀ + B Cᵀ Φᵀ + B S Bᵀ + Q_bias
C_new = Φ C + B S
S_new = S
μ_new = μ
```

同一陀螺/RPM 样本被异步事件分割成多段传播时，保留 `C` 和 `S`，不在每一段重新抽取样本噪声。偏置随机游走由独立 `Q_bias` 注入，强度按每平方根秒给定；实现采用三点正权 Gauss–Legendre 求积和剩余区间的离散映射。这是随姿态、速度变化的求积近似，不声称所有通道都完成精确连续离散化。

## 比力和原始 UWB 观测

加速度计的机体系比力模型为：

```text
accel_m = Fᴮ(q,v,RPM_m)/m + ba + η_force/m + n_acc
h_acc = (Fᴮ(q,v,RPM_m) + μF)/m + ba

H_acc = [0, Jv/m, Jθ/m, I, 0]
D_acc = [0₃×₃, I/m]
R_acc = diag(acc_std²)
```

`R_acc` 只加入独立的加速度计采样白噪声。模型力误差和 RPM 映射误差已经存在于 `S`，不会再次作为一份独立观测噪声相加。加速度计白噪声标准差按单次采样给定，不按传播区间长度另行缩放。

UWB 使用与阶段二相同的原始距离模型。对基站 `aᵢ`、机体系杆臂 `l` 和视线单位向量 `eᵢ`：

```text
t_tag = p + R(q)l
hᵢ = ||t_tag − aᵢ||
eᵢ = (t_tag − aᵢ)/hᵢ
H_uwb,i = [eᵢᵀ, 0, −eᵢᵀR(q)[l]×, 0, 0]
D_uwb = 0
```

UWB 虽不直接观测辅助量，仍会通过 `C` 条件化它们。测距噪声固定，有限负测距保留为原始观测，不按结果残差调权。

## 完整联合 Joseph 更新与右局部重置

对任一观测，记残差 `r=z−h`，联合观测矩阵 `L=[H,D]`，独立观测噪声为 `Rz`。实现使用完整 21 维联合协方差：

```text
Ω = L Σ Lᵀ + Rz
K = Σ Lᵀ Ω⁻¹
Δ = K r
Σ_cond = (I − KL) Σ (I − KL)ᵀ + K Rz Kᵀ
```

代码通过线性求解计算增益，不显式构造逆矩阵。`Δ` 的前 15 维注入名义状态，其中 `q ← q ⊗ Exp_q(Δθ)`；后 6 维加入辅助量条件均值 `μ ← μ + Δu`。注入后执行右局部姿态误差重置：

```text
G = diag(I₆, Jr(Δθ), I₆, I₆)
Σ_new = G Σ_cond Gᵀ
```

这里前 15 维的分块为位置/速度、姿态、两类偏置，最后 6 维为辅助量。重置作用于完整联合矩阵，因此同时修正姿态与公开状态、辅助量之间的交叉协方差。

## 异步输入替换与固定力先验

收到新陀螺样本时，仅令新陀螺辅助量的均值为零，协方差为 `diag(gyro_std²)`，并将其与状态、另一辅助量的交叉块清零。保留公开 `P`、力误差条件均值 `μF`、力协方差 `S_FF` 和状态到力的交叉项 `C_F`。

收到新 RPM 时，执行对称的块替换，保留当前陀螺辅助量及其与状态的完整边缘分布。新力误差的均值设为零，先验为：

```text
S_FF,new = diag(model_force_std²) + J_RPM diag(rpm_std²) J_RPMᵀ
model_force_std = [0.25, 0.25, 0.25] N
```

`J_RPM` 是名义机体系力对四个测量 RPM 的雅可比。TCN 当前预测按给定条件输入处理，因此 Physics-EKF 和 Hybrid-EKF 使用相同的名义 RPM 推力雅可比及相同固定力标准差。替换时只丢弃被替换变量，保留另一变量的边缘分布；此前观测造成的另一个辅助量的条件均值和状态交叉项不会一起清零。

固定 `0.25 N` 是每次新 RPM 的模型力误差先验标准差，后续观测可以条件化其后验协方差。它不是未知外力随机游走强度，也不是从测试残差估计的自适应权重。

## 因果 TCN 输入和真实训练目标

网络在实际 100 Hz RPM 事件上构造特征；每个时刻只查找时间戳不晚于当前 RPM 的最近陀螺测量：

```text
x_k = [gyro_m,x, gyro_m,y, gyro_m,z, RPM_m,0, RPM_m,1, RPM_m,2, RPM_m,3]
W_k = [x_(k−9), …, x_k] ∈ R¹⁰×⁷
F_residual,kᴮ = TCN(W_k)
```

10 个样本首尾跨度为 90 ms，通常称约 0.1 s 历史。输入是未经真实偏置修正的测量陀螺和测量 RPM，不含真值速度、真实转速、气动力或未来样本。满 10 样本前使用零残余。TCN 通过左侧补零实现因果卷积，默认 3 层、32 通道、卷积核宽 3、膨胀率 1/2/4，每层使用跳连和 SiLU；最终时刻输出三轴机体系残余力。

离线标签仅定义为气动力差：

```text
y_k = F_aero,trueᴮ(t_k)
      − F_aero,nomᴮ(q_true(t_k), v_true(t_k))
```

标签不含世界系未知外力，不包含质量、推力系数或 RPM 测量误差，也不以总加速度残差替代气动力。标签对齐同一 RPM 时刻保存的真值；这些真值只用于离线训练和评价。

训练使用真实 PyTorch 小批量 Adam 优化。输入每个特征、目标每个力分量的均值与标准差只在训练飞行窗口上拟合，验证和测试沿用这些统计量。输入标准差下限为 `10⁻⁵`，目标标准差下限为 `0.01 N`。训练目标是标准化后的逐轴均方误差，最佳 checkpoint 按验证集原始单位下的三维力 RMSE 选择，测试集只在训练结束后评价。

整次飞行划分先于窗口汇总，窗口不跨飞行，也不把相互重叠的窗口随机拆入不同集合。默认训练种子为 100–111、验证为 200–202、测试为 300–302；每条飞行具有独立种子及配置，并生成不同幅度、周期、方向的轨迹。三类划分的飞行标识和种子互不重合，保存配置、测量、真值、输入指纹和来源清单。

正式实验必须加载已训练 checkpoint，并核验整飞行标识、训练/验证测量特征指纹和训练/验证种子，截取训练飞行也不能作为独立实验。还要核对名义线性阻力、二次阻力和空气速度与训练标签定义一致，避免旧残余标签与新气动模型重复补偿。名义质量和推力系数不参与气动标签相减，独立记录其配置；这种接口允许性不构成跨参数条件下预测准确性的保证。

## 学习历史噪声的条件近似范围

TCN 使用多个历史陀螺与 RPM 测量，这些测量的噪声可能已经影响运动状态，也可能被相邻窗口重复使用。当前实现将已产生的 TCN 输出视为给定测量历史后的条件预测，并使用固定力误差先验近似其剩余误差。该近似没有显式展开全部历史输入噪声、网络输出误差与状态的联合分布，也没有保持跨 RPM 周期的学习误差相关性。

因此，当前周期内的模型力误差在预测和比力更新中共享、当前陀螺样本跨分段传播的相关性被保存；这不等于完整表达了任意 TCN 历史噪声的全部相关性。新周期独立先验属于本项目的条件误差建模假设。有限陀螺/RPM 历史未必唯一确定平移速度和气动力，模型误差及定位误差均须在独立飞行上如实报告。

## 调度、初始化和公平比较

事件调度先用旧输入传播到当前时刻，再接收当时的新陀螺和 RPM；新 RPM 同时更新 TCN 历史及持有残余。随后在当前时刻先做 UWB 更新，再做新加速度计样本的比力更新。所有输入时间严格递增，禁止未来输入或回填过去。

初始化复用阶段二的首帧 UWB LS：由天线位置和独立姿态先验计算机体位置，保留杆臂引起的位置与姿态交叉协方差；速度、姿态、偏置及其先验来自独立估计配置。首帧 UWB 只初始化一次，不再次用于原始测距更新。初始时刻若恰有加速度计样本，动力学滤波器可以对同一公开先验执行首次比力条件化，因此初始化后的后验不要求与阶段二 ESKF 完全相同。

在线调度仅接受 `imu/uwb/rpm` 观测包，先完成估计与结果保存，实验入口随后才加载真值评价。四方法在相同共同 UWB 时间戳比较天线位置 `p+R(q)l`；纯 LS 直接给出天线位置，不借助真实姿态转换成机体位置。各滤波器的完整状态误差按各自输出事件时间轴另外报告。

## 0.2 s 离线局部常输入预测

`evaluation/model_prediction.py` 另外评价 `h=0.2 s` 的局部模型预测。每个有效 RPM 起点使用真值位置、速度和姿态 `(p₀,v₀,q₀)` 初始化，只在离线评价中使用这些起点条件。模型使用起点测量 RPM 和起点之前已经产生的最近 TCN 残余，缺少历史时残余取零：

```text
a₀,physics = R(q₀) F_physicsᴮ(q₀,v₀,RPM_m,0)/m + [0,0,−g]ᵀ
a₀,hybrid = a₀,physics + R(q₀) F_residual,heldᴮ/m

Δv_pred = a₀ h
p_pred = p₀ + v₀ h + a₀ h²/2
```

在整个预测区间保持起点姿态、RPM、残余力和起点预测加速度，不逐步更新阻力、姿态或输入，也不使用滤波器条件化得到的力辅助均值。评价分别比较起点加速度、终点速度增量和终点位置；中间真值不用于重置预测。

因此，这是具有真值起点条件的短时局部常输入、常加速度预测，不是完整非线性滚动仿真，也不属于在线滤波定位性能。两种模型共用同一批有效起点和精确关联的真值终点；无法匹配或越界的样本单独计数，不插值、不读取未来残余。三维 RMSE 统一为 `sqrt(mean(sum(error², axis=1)))`。

## 证据与结论范围

实现保存训练曲线、验证选择轮次、独立测试残余预测、checkpoint、训练集归一化、飞行划分与来源散列，并分别保存滤波输出、创新和推理耗时。验证覆盖物理力雅可比、离散传播/比力雅可比、显式联合 Gaussian 条件化、辅助量异步替换、协方差半正定、因果前缀一致和真值隔离。

这些实现与数值验证支持所述离散算法和数据边界，不证明任意轨迹或参数下的学习模型都改善定位。单次飞行的 NIS/NEES 和重叠窗口具有时间相关性，仅作描述统计，不据此声称蒙特卡洛一致性、置信区间或一般优越性。

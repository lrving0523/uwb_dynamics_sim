# 阶段二估计方法与实现约定

## 状态与旋转误差

名义状态为位置 p、速度 v、四元数 q、加速度计偏置 ba 和陀螺偏置 bg。公开误差状态 15 维，顺序为 `[δp,δv,δθ,δba,δbg]`。四元数为 Hamilton wxyz，表示机体 FLU 到世界 ENU，局部旋转满足 `q_true=q⊗Exp(δθ)`。

旋转指数、对数和右雅可比使用 [Solà 的局部旋转约定](https://arxiv.org/abs/1711.02508)。右雅可比满足 `Exp(φ+dφ)≈Exp(φ)Exp(Jr(φ)dφ)`。零附近采用级数避免消减误差；q 和 −q 表示相同姿态，主值旋转角不超过 π。

## 输入与离散传播

当前已经收到的 IMU 样本为 am、wm，扣除偏置和当前样本噪声的条件均值后记作 f、ω。预测一个区间 dt：

```text
R_half = R(q) Exp(ω dt/2)
a      = R_half f + [0,0,-g]
p_new  = p + v dt + a dt²/2
v_new  = v + a dt
q_new  = q ⊗ Exp(ω dt)
```

`propagation_matrices` 对这套离散名义积分直接求一阶雅可比，并有全状态有限差分测试。它不是直接使用一个与名义积分不一致的连续 F 欧拉近似。

同时间先传播过去区间，再做 UWB 更新，最后接收用于下一段的新 IMU。首个 UWB 时刻只能使用此前已到达的最近 IMU；无可用样本时明确报错。输入时间戳严格递增，不允许未来样本回填过去。

## 当前样本的条件噪声

阶段一 IMU 的白噪声标准差对应单次实际样本。同一个样本在两个异步测距之间仍是同一次噪声抽样，不能把每段传播都视为新的独立白噪声。

因此公开状态仍为 15 维，内部额外保存当前样本六维输入噪声的条件均值 μ、协方差 S，及状态误差与该噪声的交叉协方差 C（15×6）。每次接收新 IMU 时重置 μ=0、S=配置的样本方差、C=0。设离散传播的状态雅可比为 Φ，输入噪声雅可比为 B：

```text
P_new = Φ P Φᵀ + Φ C Bᵀ + B Cᵀ Φᵀ + B S Bᵀ + Q_bias
C_new = Φ C + B S
```

测距更新时使用增广联合高斯的条件公式：状态增益 `K=P Hᵀ Ω⁻¹`，当前输入噪声增益 `K_n=Cᵀ Hᵀ Ω⁻¹`，Ω 为创新协方差。状态与输入噪声均值同时条件化，S 更新，C 更新；后续预测扣除 μ。这个短期辅助量在下一次 IMU 到达时丢弃，不作为未知外力、模型残差或持久运动状态。

这种输入噪声处理是本项目离散观测模型的实现选择，不将其归为 Solà 文献直接给出的额外算法。测试用线性解析例验证拆分/整段传播与条件化；独立审查另用显式 21 维联合高斯和有限差分进行核对。

## 偏置过程噪声的近似范围

偏置随机游走按连续时间强度建模，Q_bias 采用三点正权 Gauss–Legendre 求积，每项为映射后的协方差，因此保持半正定。剩余区间的传递使用中点离散雅可比。

无转动时，加速度偏置对平移的多项式通道可精确求积；陀螺偏置经比力到位置的高阶耦合仍是近似，不能宣称全通道精确连续离散化。较低 IMU 频率、长传播间隔及高速转动需要额外子步/收敛验证。当前默认 200 Hz 验证不代表所有低频条件下具有同等精度。

## 原始距离更新与重置

天线位置 `t=p+R(q)l`，其中 l 是机体系杆臂；各基站 a 的预测距离为 `h=||t-a||`，视线单位向量 u 为 `(t-a)/h`。

测距误差雅可比的位置块是 `uᵀ`，局部姿态块是 `−uᵀR[l]×`，其余块为零。距离雅可比在预测天线与基站精确重合时未定义，明确报错。带噪测量本身不裁剪或拒绝有限负值，保持原始固定高斯模型。

采用联合测距更新和固定 R，状态 P 使用 Joseph 形式。名义状态注入后，姿态误差坐标重置块为 `Jr(δθ_hat)`，同时重置 P 和 C。代码使用线性求解计算增益，不显式求创新协方差的逆。

## 首帧与公平比较

LS 只估计三维天线位置 t，固定方差下局部协方差为 `Σt=σ²(JᵀJ)⁻¹`，不以残差调整噪声。纯 LS 无姿态信息，因此与 ESKF 只在相同 UWB 时刻比较天线位置。

ESKF 首帧使用 LS 的 t 与独立姿态先验 q0，`p0=t−R(q0)l`。令 `A=R(q0)[l]×`，初始协方差包含：

```text
P_pp     = Σt + A P_θθ Aᵀ
P_pθ     = A P_θθ
P_θp     = P_pθᵀ
```

此时变换回天线位置的局部协方差恰为 Σt，避免将姿态杆臂不确定性重复计入。首帧距离只做初始化，后续才做原始距离更新。

估计器不接收任何真值；完整科学结果先保存，离线评价才加载真值。NIS/NEES 的单次时间序列有时间相关性，本项目仅作描述统计，不据此报告蒙特卡洛置信区间或普遍一致性结论。

# 阶段一实施计划

> 执行说明：按 superpowers:executing-plans 的逐任务测试流程执行；独立模块使用并行子代理，集成后另行审查。

**目标：**交付可运行、可验证、可复现的六自由度飞行与多频传感器数据生成器。

**架构：**刚体与电机层、传感器层及事件调度/数据层分离，以设计文档中的接口集成。保留当前工作区以包含用户已有配置修改，避免创建不含该修改的新工作树。

**技术栈：**Python 3.12、NumPy、PyYAML、Matplotlib、pytest。

**规格：**`docs/superpowers/specs/2026-10-19-phase-one-design.md`。

## 全局约束

- 所有新增注释、文档和图形说明使用中文；变量名和数据字段使用稳定英文接口。
- 仅实现阶段一；现有 estimator/models/factors/robust 不添加算法。
- SI 单位；RPM 显式转换为 rad/s；世界 ENU、机体 FLU、四元数 wxyz。
- 原有配置数值保留，以新键扩展；不提交用户工作、不推送。

## 审查重点

1. 非整数比频率及非整周期终点不丢样、不重复，不伪造终点观测。
2. 极限转速、不可能悬停、非有限配置应明确报错。
3. 倾斜姿态下比力及天线杆臂旋转必须正确。
4. 关掉某传感器或改变其噪声不串扰其他 RNG。
5. 真值与测量文件独立，输出文件可自描述并能从保存配置重跑。
